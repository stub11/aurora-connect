# Security policy

Report vulnerabilities privately through GitHub private vulnerability reporting if enabled; do not post credentials or exploit details publicly. Threat model: compromised relay, stolen phone, interception, DNS/IPv6 leaks, routing errors and outages. Use established cryptography, authenticated endpoints, least privilege, key revocation and no open proxy. No public SSH/RCI exposure. Never log keys or tokens. No third-party relay without authorization. Fail closed when lockdown is enabled. No stable release before security review.
