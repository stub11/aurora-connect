# Аппаратная очередь

## H0 — preflight и доступность
НЕ ПРОВЕРЕНО. Скачать router/preflight.sh из проверенного PR после CI, проверить содержимое, запустить `sh preflight.sh > preflight-report.txt` через SSH на собственном роутере. Файл отчета сохраняется на стороне запуска; предпочтительно перенаправить stdout SSH в файл на ПК. Не публиковать IP, ключи, SSID или конфиги. Приложить очищенный отчет к issue #1. PASS диагностики: отчет заканчивается END, ABI и возможности определены; это не PASS VPN. На телефоне сравнить Wi-Fi/LTE и период ограничений, используя только уже настроенные собственные endpoints; записать транспорт, время, handshake, успешность TCP/UDP/DNS и фактического трафика. Если endpoint отсутствует — НЕ ПРОВЕРЕНО. CGNAT сравнить WAN и внешний IP приватно, сообщить только совпадают/не совпадают/неизвестно. Никаких изменений роутера.
