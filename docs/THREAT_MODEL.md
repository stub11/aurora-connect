# Модель угроз

Активы: ключи устройств, доступ к LAN, DNS, доступность шлюза. Границы доверия: Android, домашний шлюз, собственный relay, мобильная сеть. Relay не должен получать приватные ключи WireGuard. Утеря телефона: отдельный ключ и отзыв. Утечки DNS/IPv6: проверка реальным трафиком, fail closed в lockdown. Ошибки firewall: dry-run, резервная копия собственных правил, commit-confirmed и проверенный откат. Публичный SSH/RCI запрещен. QR содержит секрет: не публиковать, не отправлять через Telegram без отдельной оценки угроз. Не доверять handshake как доказательству интернета. Все меры реализации НЕ ПРОВЕРЕНО.
